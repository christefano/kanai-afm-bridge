# kanai-afm-bridge
A tiny OpenAI-compatible server that connects KanAI for Kanboard and your Mac’s built-in, on-device AFM model (Apple Foundation Models). KanAI talks to the bridge through its local provider the same way it talks to Ollama, LM Studio, vLLM, etc., so queries about your projects and tasks get answered privately on your Mac and get displayed in KanAI.
